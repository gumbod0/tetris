# Tetris

Минимальный консольный тетрис на Python. Использует только стандартную библиотеку (`curses`).

## Запуск

```bash
python3 tetris.py
```

На Windows сначала поставьте `pip install windows-curses`.

## Управление

| Клавиша | Действие |
|---|---|
| ← → | сдвиг |
| ↑ | поворот |
| ↓ | ускоренное падение |
| Space | мгновенный сброс |
| P | пауза |
| R | новая игра после проигрыша |
| Q | выход |

## Что есть

- 7 стандартных фигур и «мешок из 7» для честной выдачи
- тень фигуры (куда она упадёт)
- превью следующей фигуры
- очки, линии, уровни (скорость растёт каждые 10 линий)
